# Dr. N. Vigeesh — Online Clinic

Static site for GitHub Pages (same model as the Dr Murshida / Dr Anish sites).

- `index.html` — main site (Diego Sevilla-style design)
- `book.html` — Cal.com calendar after UPI payment
- `consult.html` — in-website video room (Daily.co). Doctor joins with `consult.html?host=<owner token>`
- `config.js` — **edit this**: UPI ID, fees, Cal.com link, Daily room
- `img/portrait*.jpg` — Dr Vigeesh portraits
